# IELTSSHOKH design quality

## When to Use

Use this skill for branded channel visuals, campaign landing pages, interactive study UI, motion briefs, and design critique. It complements `ielts-media`: use `ielts-media` to create or edit a media asset and this skill to set visual authority and review quality.

## 1. Establish authority before design

- Request or retrieve the approved brand brief, audience, offer, purpose, surface, real copy, required dimensions, existing assets, and owner decision-maker.
- Treat the approved IELTSSHOKH knowledge base and owner decisions as authority. Use public design skills only as accelerators because external recommendations cannot decide this brand's identity.
- State missing authority, rights, or source evidence rather than inventing it.

## 2. Build a concise design brief

For every substantial visual or UI, record:

```text
Audience: …
Job / desired action: …
One promise: …
One proof: …
Surface and dimensions: …
Required copy and CTA: …
Visual thesis: …
Anti-references / avoid: …
Asset and font rights: …
Approval owner: …
```

## 3. Choose the correct workflow

| Work | Required approach |
|---|---|
| Channel post / carousel | Clear hierarchy, readable type at target size, one primary message and CTA. |
| Marketing page / campaign | Develop three materially different directions before selecting one for an important campaign. |
| Existing UI | Recover intended rules from approved assets and product evidence; do not elevate accidental implementation into a brand rule. |
| Motion | Design static composition first. Make motion explain a state change, hierarchy, or feedback event. |
| New logo / brand mark | Explore with images if helpful, but require an editable vector master and rights review before use as a final identity. |

## 4. Apply visual quality rules

- Use typography, spacing, color, imagery, and component behavior intentionally because vague "modern" styling produces generic output.
- Prefer one clear hierarchy over equal-weight cards, excessive pills, decorative gradients, or unearned glass effects because these reduce comprehension and brand distinctiveness.
- Use real copy, real proof, and approved assets because placeholders hide layout and trust problems.
- Make each direction differ in composition, type, color/material language, imagery, and motion posture because superficial variants do not support a real owner decision.
- Respect reduced-motion preferences and keep animation interruptible, restrained, and performance-aware because motion must aid comprehension rather than distract.
- Preserve source, license, and approval provenance for fonts, photos, illustrations, templates, and generated assets because availability does not grant usage rights.

## 5. Review gates

Before delivery, check:

```text
[ ] message and CTA understandable in seconds
[ ] text readable at actual target dimensions
[ ] hierarchy, spacing, contrast, and focus states are clear
[ ] desktop/mobile or required aspect-ratio layouts are checked
[ ] motion has a purpose and a reduced-motion alternative
[ ] asset and font sources/rights are recorded or marked unknown
[ ] claims, statistics, and testimonials have evidence
[ ] brand decision and approval owner are identified
```

For implemented web work, add a separate deterministic QA pass for responsive layout, keyboard/focus behavior, accessibility, broken links, console errors, and performance. Do not call an artifact production-ready without rendered inspection and an independent owner/verifier approval.

## 6. Delivery format

Return the available evidence, design brief, 1–3 direction options where applicable, a concrete execution brief or artifact, and review gaps. Label recommendations as recommendations. Never claim an unrendered brief, a screenshot, or a generated raster is production proof.

## Reference principles

This skill synthesizes the owner-approved operating rules with the public comparison in `frankxai/awesome-design-agent-skills` (reviewed 2026-11-16): separate brand authority from accelerator skills; use UI pattern intelligence, critique, motion discipline, and deterministic QA for the relevant stage rather than stacking every design skill at once.
