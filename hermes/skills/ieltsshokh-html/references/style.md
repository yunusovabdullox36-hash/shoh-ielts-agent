# IELTSSHOKH style

Sources reviewed: the Claude IELTSSHOKH HTML builder and the Writing fullscreen and Grammar Test sessions, Writing Mock 05 HTML, Reading Test 07 HTML, and the November 10–13 project notes. The Writing Mock 05 room diagrams and the Grammar Level Test C first page were visually checked. Reuse the builder assets packaged with this skill.

- Reading and Writing share the CDI interface. Use a white light theme, navy dark theme, blue accents, red IELTS mark and Academic label on the left, and a navy or white IELTSSHOKH lockup on the right. Keep the dark welcome card and compact Synonyms/Speaking strips. The header channel button says MAIN GRID. The earlier gold Writing variant was superseded by the shared Reading skin.
- Use English inside the artifact and inline SVG interface icons. Start and Resume request fullscreen from a user gesture. Keep the header toggle, fallback notice, timer, and mobile layout. Embedded visuals should work offline.
- Writing provides separate 20- and 40-minute tasks and a 60-minute full test. Keep drafts, word counts, notes and review. The teacher grades the writing. Model answers highlight useful structures without assigning a candidate a band. Review includes vocabulary and reusable practice phrases.
- Reading uses source wording, questions, checked answers, verbatim evidence, and explanations. Preserve the two-step score then answer-analysis flow. Check all-correct and mixed submissions, reveal, light and dark themes, and mobile layout.
- Grammar handouts use a white A4 page, monochrome logo, thin grey rules, clear answer spaces and a separate answer key. Use this as a design reference for PDF work.
