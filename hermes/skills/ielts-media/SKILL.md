# IELTSSHOKH media

## When to Use

Classify work as reuse, create, or edit. For source IELTS task visuals preserve the original and its attribution. For original creative work provide a concrete image brief or video script, shot list, edit timing and caption plan based on available material. Check output dimensions, text readability, asset rights, and subtitle timing. When `image_generate` is available, render covers, post images and simple illustrations from a concrete brief (no real people, no copied artwork, English text on images kept short and spell-checked), then inspect the result with `vision_analyze` before delivering. For owner photos or screenshots use `vision_analyze` first. Voice: owner voice messages arrive transcribed; offer a short voice summary with text_to_speech only when the owner wants audio. Video generation is not available; for video deliver the script, storyboard or edit list. Claim a rendered artifact only when a tool returns a real file that has been checked.
