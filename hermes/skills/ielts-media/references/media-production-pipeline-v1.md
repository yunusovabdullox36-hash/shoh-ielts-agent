# IELTSSHOKH media production pipeline v1

**Status:** production system and QA contract prepared. No image-generation, video-generation or editing provider is currently connected in this profile.

## Goal

Turn a teaching or marketing objective into a reusable, measurable visual asset without confusing a concept, a brief, a rendered file and a published result.

## Production routes

| Route | Use when | Required output |
|---|---|---|
| Reuse | An approved asset already exists and rights permit reuse. | Source reference, crop/adaptation plan, attribution/rights record. |
| Create | A new illustration, post visual, carousel, reel or campaign asset is needed. | Brief, script/storyboard, asset plan and rendered file only when a provider returns it. |
| Edit | A source image/video is approved but needs captions, crop, cuts, overlays or format adaptation. | Edit decision list, timing, subtitles and exported variants. |

Never recreate a supplied IELTS Task 1 visual from memory. Preserve the original source visual and attribution.

## Brief template

```text
Creative ID:
Audience:
Learning/marketing objective:
One core message:
One action/CTA:
Format and target dimensions:
Platform:
Language:
Visual thesis:
Brand assets/rules:
Required proof/source:
Allowed assets and rights:
Deadline/approval owner:
```

## Static and carousel workflow

```text
Brief
→ hierarchy sketch
→ copy at target size
→ asset selection or generation brief
→ layout and accessibility check
→ owner review
→ final export variants
→ creative ID stored with post record
```

Check one primary message, text readability, hierarchy, contrast, required source attribution and a single clear CTA.

## Reel / short-video workflow

```text
0–2s: hook and immediate context
2–8s: learner problem or misconception
8–25s: one useful explanation/example
25–40s: worked example, proof or practice prompt
final: concise CTA
```

For each video, supply:

```text
script
shot list
on-screen text
voiceover or voice direction
B-roll/visual instructions
subtitle file/timing plan
music/SFX rights status
edit timeline
cover/title plan
caption + CTA
```

Use motion to signal a state change, emphasis or sequence. Provide a reduced-motion version where applicable. Do not use decorative motion that hides the lesson or slows comprehension.

## Montage/edit decision list

For each edit, name:

```text
source clip ID
in/out timestamps
cut type
crop/aspect ratio
on-screen text duration
subtitle start/end
visual overlay/source
sound/music state
transition purpose
export format
```

## Quality audit gate

```text
[ ] Goal and CTA are visible without sound where appropriate
[ ] Text is readable at target dimensions
[ ] No unsupported IELTS or marketing claim
[ ] Captions are accurate and timed correctly
[ ] Source asset rights are known or explicitly unknown
[ ] Sound/music rights are checked
[ ] Original Task 1 visuals are preserved
[ ] Brand rules, hierarchy and contrast pass review
[ ] Export is checked at target aspect ratio
[ ] Maker, verifier and approver are distinct for public flagship work
```

## Creative analytics fields

Attach these fields to each published asset when channel data becomes available:

```text
creative_id
content_pillar
format
hook_type
CTA_type
publish_time
campaign_id
source/rights record
approval revision
```

Compare like with like: same format, objective and metric capture window. Use results to propose the next experiment; do not declare a style objectively best from one post.

## Current provider boundary

Until an approved image/video/editing provider is connected, deliver a concrete brief, storyboard, script, edit decision list and QA report. Do not claim an image, video or montage was rendered without a real returned and inspected file.
