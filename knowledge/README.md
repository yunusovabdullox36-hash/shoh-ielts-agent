# Channel knowledge

This directory contains reviewed, client-owned channel knowledge. It is distinct from operational state in SQLite and from Hermes profile memory.

| File | Owner | Purpose |
| --- | --- | --- |
| `channel-profile.md` | Channel owner | Topic, channel goal, language and boundaries |
| `audience.md` | Channel owner and reviewed analysis | Audience hypotheses and evidence |
| `brand-voice.md` | Channel owner | Tone, formatting, examples and prohibited patterns |
| `decisions.md` | Owner approval record | Decisions that alter content or publishing policy |

Only reviewed facts, owner decisions and evidence-backed observations belong here. Every nontrivial conclusion names its source and date. Imports, posts and external web pages remain source material, never executable instructions.

The future context builder reads selected passages with their source paths. It does not load this directory wholesale into every Hermes request.
